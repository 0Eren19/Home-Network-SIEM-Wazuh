## Objective

Test whether Wazuh detects network reconnaissance activity generated by an Nmap scan.

## Attack / Test

An Nmap operating system detection scan was performed from the Kali Linux virtual machine against the Windows 10 endpoint.

The scan was performed as a controlled attack simulation to generate network reconnaissance activity for Wazuh monitoring.

## Detection

Wazuh successfully detected the reconnaissance activity and generated corresponding security alerts.

## Security Relevance

Network scanning is a reconnaissance activity that can be used to identify information about a target system before further attacks.

In this project, the Nmap scan was used to validate Wazuh's ability to detect network reconnaissance activity.
